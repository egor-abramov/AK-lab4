# Лабораторная работа №4
* Абрамов Егор P3219
* `forth | risc | neum | mc | tick | binary | stream | mem | pstr | prob1 | superscalar`

## Язык крограммирования
``` ebnf
<program> ::= <term> | <term> <program>
<term> ::= <procedure_def> | <var_def> | <instruction>

<instruction> ::= <math_op>
	            | <logic_op>
	            | <stack_op>
                | <addr_op>
	            | <io_op>
                | <loop_exp>
                | <cond_exp>
                | <number>
                | <identifier>
                | <execution_token>
                | <execute_op>

<instruction_list> ::= <instruction> | <instruction> <instruction_list>

<math_op> ::= "+" | "-" | "*"

<logic_op> ::= "and" | "not" 	

<stack_op> ::= "dup" | "drop" | "swap"

<addr_op> ::= "!" 		          
	        | "@" 		                  

<io_op> ::= "read" 		        
	      | "." 		        

<loop_exp> ::= "loop" <instruction_list> "endloop" 					                

<cond_exp> ::= "=0" <instruction>  
	         | ">0" <instruction>	  

<identifier> ::= string

<var_def> ::= "var" <identifier> | "array" <identifier>

<procedure_def> ::= ":" <identifier> <instruction_list> ";"

<execution_token> ::= "'" <identifier>

<execute_op> ::= "execute"
```

Операции:

- `+` - сложить два верхних значения на стеке, результат положить на вершину
- `-` - вычесть из второго значения на стеке верхнее, результат положить на вершину
- `*` - перемножить два верхних значения на стеке, результат положить на вершину
- `and` - выполнить побитовое «И» для двух верхних значений на стеке
- `not` - выполнить логическое отрицание верхнего значения на стеке
- `dup` - продублировать верхнее значение на стеке
- `drop` - удалить верхнее значение со стека
- `swap` - поменять местами два верхних значения на стеке
- `!` - сохранить значение с вершины стека по адресу, равному второму элементу в стеке
- `@` - загрузить на стек значение по адресу с вершины стека. 
- `var <name>` - создать переменную `<name>`
- `array <name>` - создать массив, количество слов в котором равно числа на стеке
- `read` - ввести числовое значение из потока ввода и положить на стек
- `.` - напечатать верхнее значение со стека
- `loop ... endloop` - начать выполнение цикла, тело которого ограничено `endloop`. Цикл заканчивается, если после выполнения тела цикла на стеке лежит 0. 
- `=0` - если значение на вершине стека равно 0, выполнить следующую за этим инструкцию
- `>0` - если значение на вершине стека больше 0, выполнить следующую за этим инструкцию
- `' <name>` - положить на стек Execution Token слова
- `execute` - взять Execution Token с вершины стека и перейти к выполнению кода по этому адресу
- `<name>` - положить на стек адрес переменной/процедуры `<name>`

Команды выполняются последовательно. 
Видимость данных - глобальная. 
Стековая модель вычислений.

На уровне стека все данные рассматриваются как числа. Одно и то же значение может быть интерпретироваться как число или как ASCII-символ, в зависимости от интсрукции.
Поддерживаются числовые и строковые литералы (только в инструкции ```."..."```)

## Организация памяти
Память представляет из себя единое адресное пространство из 2048 ячеек. Машинное слово - 32 бита. 

Memory-mapped I/O
#### Варианты адресации
- Непосредственная загрузка 
- Абсолютная 
- Относительная
- Косвенная
- Регистровая

#### Доступные регистры
- `PC` - адрес текущей команды
- `SP` - указатель на стек данных
- `RP` - Указатель на стек возвратов
- `X0-X4` - регистры общего назначения

#### Разделение памяти
| Ячейки        | Назначение      |
|---------------|-----------------|
| 0x0 - 0x5F7   | Основная память | 
| 0x5F8         | Поток ввода     | 
| 0x5FC         | Поток вывода    | 
| 0x600 - 0x6FF | Стек данных     | 
| 0x700 - 0x7FF | Стек возвратов  | 
Статические данные располагаются в основной памяти, динамические данные - на стеке данных.  
Строки хранятся в памяти в виде паскаль-строк. Каждый символ строки занимает машинное слово **целиком** (4 байта). Символы хранятся в памяти друг за другом.
## Система команд
#### Кодирование инструкций:
* Инструкции имеют фиксированный размер в 4 байта. 
* Первый 6 бит инструкции - код операции. 
* Регистры кодируются 3 битами.
* Адресация кодируется 3 битами

#### Директивы
Предназначены для работы со зачениями, не помещающимися в машинное слово
* `%hi(symb)`
  * Выделяет 20 старший бит числа
  * Пример: `lw r0, %hi(symb)`
  * Операция: `r0 <- (symb & 0xFFFFF000)`
* `%lo(symb)`
  * Выделяет 12 младший бит числа
  * Пример: `addi r0, r1, %lo(symb)`
  * Операция: `r0 <- r1 + (symb & 0x00000FFF)`

#### Набор инструкций
* Load Upper Immediate
  * ``lui <rd>, <k>``
  * ? такт
  * Выделяет младшие 20 бит `k`, побитово сдвигает на 12 влево и загружает в регистр `rd`
  * Операция: `rd <- (k & 0x000FFFFF) << 12`
* Move 
  * `mv <rd>, <rs>`
  * ? такт
  * Перемещает значение из регистра `rs` в регистр `rd`
  * Операция: `rd <- rs`
* Store
  * `sw <rs2>, <offset>(<rs1>)`
  * ? такт
  * Сохраняет значение из регистра `rs2` по адресу, вычисляемому как сумма значения регистра `rs1` и `offset`
  * Операция: `Mem[rs1 + offset] <- rs2` 
* Load 
  * `lw <rd>, <offset>(<rs>)`
  * ? такт
  * Загружает значение в регистр `rd` из адреса, вычисляемого как сумма  значения регистра `rs` и `offset`
  *  Операция: `rd <- Mem[rs + offset]`
* Add Immediate
  * `addi <rd>, <rs>, <k>`
  * ? такт
  * Прибавляет к значению в регистре `rs` младшие 12 бит `k`, рвсширяя знак `k`. Результат сохраняется в регистр `rd`
  * Операция: `rd <- rs + signext(k & 0x00000FFF)` 
* Add 
  * `add <rd>, <rs1>, <rs2>`
  * ? такт
  * Складывает значения регистров `rs1` и `rs2`. Результат сохраняется в регистр `rd`.
  * Операция: `rd <- rs1 + rs2`
* Substract 
  * `sub <rd>, <rs1>, <rs2>`
  * ? такт
  * Вычитает значение регистра `rs2` из регистра `rs1`. Результат сохраняется в регистр `rd`.
  * Операция: `rd <- rs1 - rs2` 
* Multiply
  * `mul <rd>, <rs1>, <rs2>`
  * ? такт
  * Умножает регистр `rs1` на `rs2`. Результат сохраняется в `rd`
  * Операция `rd <- rs1 * rs2` 
* Bitwise AND
  * `and <rd>, <rs1>, <rs2>`
  * ? такт
  * Берет побитовое И регистров `rs1`и `rs2`. Результат сохраняется в `rd`.
  * Операция: `rd <- rs1 & rs2`
* Inversion
  * `inv <rd>, <rs>`
  * ? такт
  * Битовая инверсия регистра `rs`. Результат сохраняется в `rd`
  * Операция `rd <- ~rs` 
* Jump
  * `j <k>`
  * 1 такт
  * Переход на адрес `k`
  * Операция: `PC <- k`
* Jump Register
  * `jr <rs>`
  * ? такт
  * Переход на адрес в регистре `rs`
  * Операция: `PC <- rs`
* Jump If Zero Register
  * `jz <rs>, <k>`
  * ? такт
  * Переход на адрес `k`, если в регистре `rs` записан ноль
  * Операция: `if rs == 0 then PC <- k `
* Jump And Link
  * `jal <rd>, <k>`
  * ? такт
  * Переход на адрес `k`, текущий `PC + 4` сохраняется в регистр `rd`
  * Операция: `rd <- PC + 4; PC <- k`
* Halt
  * `halt`
  * Остановка
